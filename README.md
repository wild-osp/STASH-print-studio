# STASH Print Studio

Настольное приложение для подготовки и печати фотографий в Windows. Интерфейс реализован на HTML Canvas, окно и мост к Windows Spooler — на PyQt6 и QWebChannel. Изображения отправляются в драйвер через GDI без `win32ui`; параметры DEVMODE применяются только к текущему заданию.

## Требования для сборки

- Windows 10 или новее, 64-разрядная версия Python 3
- Драйверы принтеров, на которые планируется печатать

Установите зависимости:

```powershell
py -m pip install PyQt6 PyQt6-WebEngine PyQt6-WebChannel Pillow pywin32 pyinstaller
```

Запустите приложение из исходного кода:

```powershell
py app.py
```

## Сборка автономного EXE

В каталоге проекта выполните:

```powershell
pyinstaller --noconsole --onefile --add-data "index.html;." app.py --name "STASH_PrintStudio"
```

Готовый файл будет находиться в `dist\STASH_PrintStudio.exe`. Python на рабочем компьютере устанавливать не нужно; для печати требуется установленный в Windows драйвер принтера. Если драйвер не принимает пользовательский размер страницы, приложение выбирает ближайший поддерживаемый фотобланк (не более 3% отличия); если подходящего формата нет, задание отменяется вместо незаметной печати на A4. Кнопка «Проверить настройки в драйвере...» открывает окно Epson с начальными значениями формата, качества и типа бумаги, переданными из приложения через DEVMODE. Драйвер может их переинтерпретировать или проигнорировать — обязательно сверьте отображаемые значения и при необходимости исправьте их до подтверждения. Например, установленный драйвер Stylus Photo 1410 в проверке оставил «Простая бумага» и «Текст» даже при запросе матовой бумаги и стандартного качества. Подтверждённый DEVMODE применяется к последующим заданиям этого принтера в течение текущего запуска приложения. Печать без полей не удалось предустановить общим полем DEVMODE; проверьте/включите её в окне Epson вручную. Если в драйвере выбран размер или ориентация, отличающиеся от приложения, задание будет остановлено.

## Использование

1. Загрузите фотографии кнопкой «+ Загрузить» или перетащите их в окно.
2. Настройте кадрирование, формат, ориентацию и коррекцию отдельно для каждого кадра.
3. Для фото на документы выберите размер снимка и листа; лица раскладываются на лист автоматически.
4. Выберите принтер. Нажмите «Проверить настройки в драйвере...», сверьте качество, бумагу, формат, ориентацию и печать без полей в окне Epson, при необходимости исправьте и подтвердите. Затем печатайте текущий кадр или все отмеченные как готовые.
