# STASH Print Studio

Настольное приложение для подготовки и печати фотографий в Windows. Интерфейс реализован на HTML Canvas, окно и мост к Windows Spooler — на PyQt6 и QWebChannel. Изображения отправляются в драйвер через GDI без `win32ui`; параметры DEVMODE применяются только к текущему заданию.

## Требования для сборки

- Windows 10 или новее, 64-разрядная версия Python 3
- Драйверы принтеров, на которые планируется печатать

Установите зависимости:

```powershell
py -m pip install PyQt6 PyQt6-WebEngine PyQt6-WebChannel Pillow pywin32 pyinstaller
```

Запустите приложение из исходного кода:

```powershell
py app.py
```

## Сборка автономного EXE

В каталоге проекта выполните:

```powershell
pyinstaller --noconsole --onefile --add-data "index.html;." app.py --name "STASH_PrintStudio"
```

Готовый файл будет находиться в `dist\STASH_PrintStudio.exe`. Python на рабочем компьютере устанавливать не нужно; для печати требуется установленный в Windows драйвер принтера. Если драйвер не принимает пользовательский размер страницы, приложение выбирает ближайший поддерживаемый фотобланк (не более 3% отличия); если подходящего формата нет, задание отменяется вместо незаметной печати на A4. Список типов бумаги загружается из выбранного драйвера Windows; в задание передаётся его точный идентификатор, а не обобщённые категории «глянцевая/матовая».

Для Epson список режимов качества загружается из возможностей драйвера и зависит от выбранной бумаги и режима полей. Качество и физический режим «Без полей» приложение передаёт в драйвер через PrintTicket, преобразуя его в закрытый DEVMODE Epson для каждого задания; открывать окно настроек Epson не требуется. «Без полей» доступно только для фотобумаги; неподдерживаемые драйвером сочетания отклоняются, а на неподходящей бумаге приложение принудительно оставляет поля. Для других принтеров доступны стандартные настройки DEVMODE и проверка в окне драйвера. Если в драйвере выбран размер или ориентация, отличающиеся от приложения, задание будет остановлено.

## Использование

1. Загрузите фотографии кнопкой «+ Загрузить» или перетащите их в окно.
2. Настройте кадрирование, формат, ориентацию и коррекцию отдельно для каждого кадра.
3. Для фото на документы выберите размер снимка и листа; лица раскладываются на лист автоматически.
4. Выберите принтер, тип бумаги и качество из доступных режимов. Для Epson режимы качества загружаются автоматически; для фотобумаги при необходимости выберите «Без полей» рядом с качеством. На других моделях при необходимости проверьте параметры через окно драйвера. Затем печатайте текущий кадр или все отмеченные как готовые.
