# STASH Print Studio

Настольное приложение для подготовки и печати фотографий в Windows. Интерфейс реализован на HTML Canvas, окно и мост к Windows Spooler — на PyQt6 и QWebChannel. Изображения отправляются в драйвер через GDI без `win32ui`; параметры DEVMODE применяются только к текущему заданию.

## Требования для сборки

- Windows 10 или новее, 64-разрядная версия Python 3
- Драйверы принтеров, на которые планируется печатать

Установите зависимости:

```powershell
py -m pip install PyQt6 PyQt6-WebEngine PyQt6-WebChannel Pillow pywin32 pyinstaller
```

Запустите приложение из исходного кода:

```powershell
py app.py
```

## Сборка автономного EXE

В каталоге проекта выполните:

```powershell
pyinstaller --noconsole --onefile --add-data "index.html;." app.py --name "STASH_PrintStudio"
```

Готовый файл будет находиться в `dist\STASH_PrintStudio.exe`. Python на рабочем компьютере устанавливать не нужно; для печати требуется установленный в Windows драйвер принтера. Если драйвер не принимает пользовательский размер страницы, приложение выбирает ближайший поддерживаемый фотобланк (не более 3% отличия); если подходящего формата нет, задание отменяется вместо незаметной печати на A4. Список типов бумаги загружается из выбранного драйвера Windows; в задание передаётся его точный идентификатор, а не обобщённые категории «глянцевая/матовая». Качество и печать без полей Epson хранит в собственных параметрах драйвера, которые нельзя надёжно задать общими полями DEVMODE. Поэтому перед печатью проверьте и выставьте их в окне «Проверить настройки в драйвере...», затем подтвердите диалог. Подтверждённый DEVMODE, включая выбранные там качество и печать без полей, применяется к последующим заданиям этого принтера в течение текущего запуска приложения. Если в драйвере выбран размер или ориентация, отличающиеся от приложения, задание будет остановлено.

## Использование

1. Загрузите фотографии кнопкой «+ Загрузить» или перетащите их в окно.
2. Настройте кадрирование, формат, ориентацию и коррекцию отдельно для каждого кадра.
3. Для фото на документы выберите размер снимка и листа; лица раскладываются на лист автоматически.
4. Выберите принтер и тип бумаги из списка, загруженного из его драйвера. Нажмите «Проверить настройки в драйвере...», задайте или сверьте качество, формат, ориентацию и печать без полей в окне Epson, затем подтвердите диалог. Затем печатайте текущий кадр или все отмеченные как готовые.
